# SciVerse frontend

React + TypeScript + Vite. Deploy this folder to Vercel.

```bash
npm ci
cp .env.example .env
npm run dev
```

Use `npm run check`, `npm test`, and `npm run build` for validation.
Set `VITE_API_BASE_URL` to the backend HTTPS origin before the production build.
See [deployment instructions](../DEPLOYMENT.md).

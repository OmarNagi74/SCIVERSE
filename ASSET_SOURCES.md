# TerraTwin visual asset sources

TerraTwin is an independent prototype and does not use NASA logos, mission insignia, or language that implies NASA endorsement. The interactive Explorer identifies visual planetary surfaces as decorative visualization treatments, not analytical map layers. The hero uses original TerraTwin artwork (`client/public/assets/terratwin-hero.webp`, 1920 × 823 WebP); it contains no agency marks or data claims and is bundled locally.

The Earth visual context is informed by NASA Goddard Space Flight Center Scientific Visualization Studio’s equirectangular Earth image, which notes Blue Marble Next Generation source data and requests credit to NASA/GSFC and NASA’s Earth Observatory. Reference: https://svs.gsfc.nasa.gov/3615/.

The lunar source preview (`assets/source/moon-surface.jpg`, 1024 × 449 JPEG) is a reduced-resolution preview of the USGS Astrogeology LROC WAC GLD100 lunar topography product. The source record identifies the LROC Team and named GLD100 authors, USGS Astrogeology as publisher, public-domain access, and a request to cite the authors. The source DEM is near-global, spanning 79°S to 79°N. The original source is preserved unchanged and is not served from the public directory. `scripts/mask_moon_coverage.py` creates `client/public/assets/moon-surface-equirectangular.png`, a lossless 1024 × 512 (2:1) display derivative compatible with the sphere UV mapping. It maps every one of the source’s 449 rows into the exact 79°N–79°S band: output coverage boundaries are y=31.288889 (79°N) and y=480.711111 (79°S). Only the true 11° polar caps receive the opaque gridded no-data treatment; the fractional boundary rows are area-mixed rather than stretched into the caps. The validator checks dimensions, geographic boundaries, complete source-row participation, a row-coded independent geographic transform, no-data-only fully polar rows, the active Moon renderer URL, and a byte-for-byte in-memory expected raster reconstructed from the preserved source. South-polar reference contexts remain selectable, but are explicitly identified as outside texture coverage. The derivative is a visualization texture only, not a georeferenced analytical layer, and no elevation values are extracted from it. Reference: https://astrogeology.usgs.gov/search/map/moon_lroc_wac_dtm_gld100_118m.

The Mars visual texture (`client/public/assets/mars-surface.jpg`, 1024 × 512 JPEG preview) is a reduced-resolution preview of the USGS Astrogeology Mars Viking colorized global mosaic. The source record identifies USGS Astrogeology as publisher, NASA Ames as originator, public-domain access, and an image map derived from the Viking colorized mosaic blended over MDIM 2.1. Its documented illumination, photometric, and control limitations mean it must not be treated as a scientific analysis layer. The bundled preview is used only to texture the interactive sphere. Reference: https://astrogeology.usgs.gov/search/map/mars_viking_colorized_global_mosaic_232m.

The implementation intentionally does not embed the full archival raster products, which are large (the cited USGS source pages list approximately 10 GB for the lunar DTM and 12 GB for the Mars mosaic) and require a reviewed processing/tile pipeline. When future dataset adapters are added, TerraTwin will retain product ID, release/version, license, coordinate definition, processing provenance, coverage, and limitations alongside every layer.


## Phase 4 — bounded lunar terrain (separate from color imagery)

The actual terrain proof uses SLDEM2015, product `SLDEM2015_512_60S_30S_315_360`, PDS dataset `LRO-L-LOLA-4-GDR-V1.0`, V2.0. The official PDS3 JP2 label is linked at https://imbrium.mit.edu/EXTRAS/SLDEM2015/TILES/JP2/SLDEM2015_512_60S_30S_315_360_JP2.LBL and the numeric 16-bit JP2 at https://imbrium.mit.edu/EXTRAS/SLDEM2015/TILES/JP2/SLDEM2015_512_60S_30S_315_360.JP2. The source tile spans 60°S–30°S, 315°E–360°E at 512 pixels/degree in simple cylindrical, body-fixed MEAN EARTH/POLAR AXIS OF DE421 coordinates. It is a merged LRO LOLA / SELENE-Kaguya terrain-camera DEM relative to the 1,737,400 m radius. The auxiliary source metadata records a 0.5 m/count scale and `−32768` no-data.

The compact derived asset `client/public/assets/terrain/tycho-sldem2015.i16` is a 129×129 regional subset for 40°–46°S, 15°–7°W (same region as 345°–353°E). Its browser interaction is restricted to the existing Tycho context and the stated patch. The grid is sampled from the numeric DEM, not from `moon-surface-equirectangular.png`, and never supplies unqualified measurements to the UI. The existing GLD100 preview remains an independent color-only layer; its global UVs are aligned to the DEM geographic grid for visualization, not claimed as a source-image coregistration product. The regional relief uses the verified JP2 decode `signed count = unsigned pixel − 32768`; raw zero decodes to the AUX no-data sentinel `−32768`. The NASA/PDS LOLA FAQ gives the stored-height formula as `(data value × 0.5) + 1,737,400 m`; the local mesh uses only the source-derived relative component `count × 0.5 m` for vertex relief. Regional display relief can be exaggerated by a clearly labeled visual multiplier. The static mesh excludes triangles containing no-data samples. The patch is not applied outside those bounds; neither it nor GLD100 texture covers the south-polar Shackleton area.

An offline source preparation script records URL, product/version, coordinate convention, crop pixel bounds, sample scale, no-data count, source checksum, derived asset checksum and display processing limits in `client/public/assets/terrain/tycho-sldem2015.json`. The multi-megabyte archive source is kept under ignored `assets/source/` and is not shipped. For fresh generation see the commands in `README.md`. Re-run source exactness with `pnpm validate:tycho-terrain`.
